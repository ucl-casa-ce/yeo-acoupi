# Reference & Sample Data (`data/`)

This folder contains the reference species catalogs, field deployment imagery, and sample recordings used by the **Yeo Valley Bioacoustic Visualisation** (`yeo-vis.py` and `recording_explorer.py`):

* **[`yeo_valley_bird_species_list.csv`](yeo_valley_bird_species_list.csv)**: Master lookup table mapping numeric edge IDs (`species_id`) to 208 British bird species (`class_name`, `common_name`, `species`).
* **[`yeo_valley_bat_species_list.csv`](yeo_valley_bat_species_list.csv)**: Master lookup table mapping numeric edge IDs (`species_id`) to 17 British bat species.
* **[`assets/img/`](assets/img/)**: Field installation photographs (`UNOQ-14-YV.jpeg` through `UNOQ-31-YV.jpeg`) displayed on the **Info + Map** page of the dashboard.
* **[`UNOQ/20260531/`](UNOQ/20260531/)**: Sample 3-second ultrasonic bat `.wav` recordings and `.png` spectrograms captured during testing using an Ultramic 192 kHz microphone.
